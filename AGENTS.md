# AgentDrive · agent instructions

AgentDrive is file storage for AI agents: drives, folders and versioned
artifacts behind a `/v0` REST API and an MCP transport, with public share
links that render artifacts as styled pages. It is FastAPI + PostgreSQL + an
object store (Google Cloud Storage or a local directory), with a TypeScript
MCP transport under `mcp/` and a React component library under
`design-system/`. `CONTRIBUTING.md` has the human-facing version of this page.

## Commands

```bash
uv sync                                                   # Python deps (uv-managed venv)
docker compose up -d                                      # dev Postgres + the GCS emulator
uv run python -m agentdrive.scripts.apply_schema          # migrations/ + schema.sql → $DATABASE_URL
uv run uvicorn agentdrive.app:app --reload --port 8000    # the API alone
uv run ruff check                                         # the only linter; there is NO formatter — never run `ruff format`
uv run pytest -n auto --ignore=tests/browser              # needs `docker compose up -d`
make css                                                  # regenerate the served stylesheet from design-system/
python scripts/check_public_snapshot.py                   # the publish gate
scripts/selfhost-smoke.sh --down                          # compose.selfhost.yml, end to end
npm ci && npm test --workspace @tokencanopy/agentdrive-mcp   # the MCP transport
```

There is no mypy and no `make lint`/`make test` target; don't invent them.
`STORAGE_BACKEND=fs STORAGE_FS_ROOT=<dir>` runs the suite on the filesystem
store instead of the emulator.

## Two ways to run it

- **Self-hosted** (`compose.selfhost.yml`, README "Self-host in ten
  minutes"): `AUTH_MODE=local`. The installation mints opaque `adk_` API keys
  with `python -m agentdrive.keys` (`init`, `create`, `list`, `revoke`); one key
  works on `/v0`, the SDKs and `/mcp`; a key's scopes are fixed at creation.
  Keys live hashed in `local_api_keys`, principals in `local_principals`.
- **Hosted** (`AUTH_MODE=hub`, the default): bearer tokens are JWTs issued by
  the Token Canopy Hub and verified offline against its JWKS
  (`identity/product_token.py`). The `/v0` API and the MCP transport verify
  different audiences, and neither accepts the other's token.

In both modes the routes see the same `V0ActorContext` (`identity/actor.py`),
so authorization, grants and scope checks are one code path.

## Where things are

- **v0 API** — `src/agentdrive/api/v0_*.py` routers over `core/v0_*.py`
  mutators, conformance-pinned to `api/v0-operations.json` and
  `tests/openapi.golden.json`. A route change updates the golden file in the
  same change.
- **Storage** — `storage/`: one `ObjectStore` protocol (`base.py`), a GCS
  backend (`gcs.py`) and a filesystem backend (`fs.py`), chosen by
  `STORAGE_BACKEND`. Callers import the facade `agentdrive.storage`, never a
  backend; `tests/storage/test_contract.py` runs the contract against both.
- **Public read surface** — `public/`: `/s/{share_key}/`, `/a/`, `/f/`, `/v/`.
  A refusal is always the same 404, so no route reveals whether an id exists.
- **Rendering** — `rendering/`: Markdown, code, images, spreadsheets, Parquet,
  Word and PowerPoint documents, JSON/YAML/XML trees, and sanitized HTML behind
  `STATIC_HTML_RENDERING_ENABLED` (off by default).
- **MCP transport** — `mcp/server` (`@tokencanopy/agentdrive-mcp`, 24 tools,
  each declaring its scopes) and `mcp/auth` (`@tokencanopy/mcp-auth`). The
  process supervisor runs it beside the API; under `AUTH_MODE=local` it
  authenticates keys by calling the loopback ingress's `/_internal/introspect`.
  The image builds these packages from `deploy/mcp/`, whose manifests
  `deploy/mcp/sync-manifests.py` keeps in step.
- **Design system** — `design-system/` (`@tokencanopy/agentdrive-design-system`)
  owns `agentdrive.css`; the served copy under `src/agentdrive/static/` is
  generated by `make css` and never edited by hand. Read
  `design-system/docs/DESIGN-SYSTEM.md` before any template or CSS change.
  The unprefixed class names are public API.
- **Migrations** — `migrations/NNNN_*.sql` plus `schema.sql`, both applied by
  `agentdrive.scripts.apply_schema`: an empty database takes `schema.sql` alone;
  anything else replays pending migrations. Never edit a shipped migration;
  fold a new one's end state into `schema.sql` in the same change.
- **Formal model** — `specs/tla/ArtifactGC.tla`, the garbage collector's
  safety argument; its TLC configs run in CI.

## Rules that are easy to break

1. **Nothing private in this repository.** It is public, history included. Use
   `user@example.com`, `*.example.test` and fictional ids in code, tests and
   docs. `scripts/check_public_snapshot.py` enforces the common cases in CI.
2. **Reserved single-letter URL prefixes** (`/a/`, `/f/`, `/s/`, `/v/`, `/_/`)
   belong to the permalink and share surfaces; don't claim them for new
   routes. Wire ids (`drv_`, `fld_`, `art_`, `adk_`) are part of the contract.
3. **No inline CSS in templates**; add a class to the design system instead.
   The trusted share shell (`public/static/shell.css`, `shell.js`) is the one
   hand-authored exception and must stay free of inline script.
4. **Every mutation takes an `Idempotency-Key`** and every conditional write a
   precondition; the conformance suite fails a route that doesn't.
